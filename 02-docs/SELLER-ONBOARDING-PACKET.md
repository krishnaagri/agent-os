# 📦 SELLER ONBOARDING PACKET

> Har naye seller ke liye. Goal: **30 minute ka onboarding, professional impression, system-ready data.**

---

## 1. Aapko Seller Se Kya Maangna Hai (Checklist)

| # | Item | Format | Kyun |
|---|------|--------|------|
| 1 | **Flipkart API access** (App Key + Secret + Seller ID + Location IDs) | Seller Hub → API Access | Listings/orders/reports automation |
| 2 | **User role** aapke naam se (Operations Manager + Catalog Manager) | Seller Hub → Users | Dashboard access |
| 3 | **Cost Price Sheet** (product-wise: SKU, FSN, cost, MRP, current price) | Excel/CSV | P&L + aapka % + price floor |
| 4 | **Current stock** (product-wise, location-wise) | Excel | Inventory agent |
| 5 | **Settlement access** ya monthly statements | Seller Hub / email | Reconciliation |
| 6 | **Target & constraints** (monthly GMV target, ad budget cap, discount limits) | Call mein | Strategy |
| 7 | **Emergency contact + response time** | WhatsApp | Escalations |

## 3. Onboarding Timeline (Standard: 3 Din)

| Din | Kaam | Kya Complete Hoga |
|-----|------|------------------|
| **D1** | Docs receive + verify, user role verify, cost sheet validate (margins check karo — kabhi-kabhi sellers ko apna margin nahi pata hota, yahan value add karo) | Data clean |
| **D2** | System mein entry: sellers.csv, rate card, dashboard row, price floors set, stock upload | System live |
| **D3** | Dry-run: 1 din ka data test, digest aapko + seller ko nahi, issues fix | Ready for live |

---

## 4. Pilot Strategy (Pehle 2 Sellers)

1. **Selection:** Jo 2 sellers sabse cooperative + data clean hain, unse shuru karo
2. **First 2 hafte:** Listings publish = aapki approval (dry trust building)
3. **Week 3:** Sab green hai toh auto-publish on
4. **Week 4:** Un 2 sellers ke results ko baaki 8 ko dikhao — *"Yeh hua aapke account pe, yeh hoga aapke account pe"* — best selling pitch yehi hai

---

## 5. Red Flags Onboarding Mein (Professional Rahe)

- Seller cost price nahi batana chahta → bina cost ke P&L nahi hoga; explain karo ki yeh confidential hai (NDA signed), sirf pricing decisions ke liye
- "Sab kuch auto kar do" → Approval matrix dikhao: paise wale cheezein aapke (seller ke) approval pe — yeh trust badhata hai, confidence nahi
- Multiple locations / FBF mix → Phase 2 mein lo; pehle single-location sellers

---

## 6. First 30 Din Ka Promise (Seller Ko Dikhao)

> "Pehle 30 din mein aap dekhenge:
> - Daily 7 baje aapka exact P&L — guess khatam
> - Cancellations 50%+ kam (stock-sync se)
> - RTD breaches almost zero
> - Har settlement ka reconciliation — over-deducted commission wapis
> - Weekly report jo aap directly apne business plan mein use kar sako"

Yeh 5 cheezein system deliver karta hai — baaki sab time se aayenge.
